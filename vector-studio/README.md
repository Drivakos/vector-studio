# Vector Studio

Native vector illustration app in Rust. Phase 1: draw, edit, save, reopen and export.

## Run

Opening CorelDRAW files needs libcdr: `brew install libcdr`. Without it the app still builds, and says it cannot read them.

```bash
export PATH="/opt/homebrew/opt/rustup/bin:$PATH"
cargo run -p vector-studio
cargo run -p vector-studio -- path/to/drawing.vstudio
cargo test --workspace
cargo run -p vs-io --example sample_logo -- /some/dir   # builds, saves, reopens and exports a sample
```

## Layout

| Crate | What it holds |
|---|---|
| `crates/core` (`vs-core`) | Document, pages, objects, transforms, hit-testing, align/order ops, node editing, undo history. No UI or GPU code |
| `crates/io` (`vs-io`) | Native `.vstudio` format (versioned JSON), SVG, PNG (resvg) and PDF (krilla) export |
| `crates/render` (`vs-render`) | Viewport maths, ruler ticks, Vello scene building |
| `app` | eframe/egui shell: native menu (macOS), title bar and toolbar, property bar, toolbox, dockers, palette, GPU canvas. A library (`src/lib.rs`) with a thin binary (`src/main.rs`), so the end-to-end tests can start it. File dialogs go through a `Dialogs` trait; custom widgets report accessible names (`src/a11y.rs`) |
| `app/tests/e2e` | End-to-end tests: the whole app driven through its window (see [TESTING.md](TESTING.md)) |
| `app/layout/workspace.json` | Every menu item. Ids without a `Command` render disabled |

## What works

Phase 0 shell: native macOS menu bar from `workspace.json`, toolbox (17 groups, 60 tools, flyouts), per-tool property bar, dockable dockers, Vello canvas with rulers, zoom and pan, pages, layout restore.

### Window layout

Dark theme, laid out as follows:

| Area | What it is |
|---|---|
| Title bar + toolbar | Drawn by the app under a transparent title bar. Items with captions: Zoom, View Modes, Group, Ungroup, Lock, Unlock, Alignment, Mirror, Arrange, View (Rulers, Grid, Guidelines), Snap To, and a Dockers toggle. AI Generate and Get More are left out (online services) |
| Property bar | Stacked fields with steppers. Pick tool, nothing selected: page size, W/H, orientation, units, nudge, duplicate distance |
| Toolbox | 17 groups with separators |
| Dockers | One docker shown at a time: header with close button and title, vertical icon strip to switch, ••• for the full list |
| Palette | Vertical, no-colour swatch on top, scroll chevron at the bottom |
| Canvas | Grey desk (#5a5a5a), white page without border or shadow; page navigator with + on both sides and page tabs |
| Off by default | Rulers and status bar; View toolbar and View menu turn them on |

View modes (View menu or the View Modes dropdown): Enhanced draws fills, outlines and bitmaps; Normal draws them without anti-aliasing or bitmap smoothing, so every edge is hard (it is drawn on the CPU, as the GPU renderer always smooths; Simulate Overprints does not apply in it); Wireframe draws every outline as a one-pixel line, with no fills, bitmaps as frames and PowerClip contents unclipped; Pixels draws the page as the bitmap it would export to at the Export window's resolution (300 dpi unless changed), magnified without smoothing once its pixels are bigger than the screen's. View > Page Sorter View shows every page as a thumbnail in place of the drawing window: click one to make it the active page, drag it onto another page's place to move it there (undoable), double-click it (or Esc, or the menu again) to go back to drawing. View > Full-Screen Preview (`F9`) fills the screen with the active page on black, in Enhanced view, without tools, selection, grid or guidelines; any key or click ends it and does nothing else. Icons are Material Symbols (outline).

Phase 1 drawing:

| Area | What you can do |
|---|---|
| Pick | Click, Shift-click, marquee select. Drag to move (Cmd = one axis). Handles scale (corners keep proportions; Cmd frees them; Shift scales from the centre). Click a selected object again for rotate handles (Cmd = 15° steps). Double-click an object to edit its nodes with the Shape tool; in a group, the object under the pointer is edited and the group stays whole |
| Freehand Pick | Pick tool flyout. Drag a loop of any shape: it selects the objects that lie wholly inside it (Shift adds to the selection; a loop around nothing clears it). Clicking, moving, the handles and the property bar work as with the Pick tool |
| Free Transform | Pick tool flyout. Click an object to select it (Shift adds), then drag from any point: the selection turns, mirrors, scales or slants about the point pressed, by the mode on the property bar. Free rotation turns by the angle the pointer sweeps; Free angle reflection mirrors across the line from the press point to the pointer; Free scale and Free skew go by how far the pointer moves against the selection's size (moving by its width or height doubles it, or slants it 45°). Cmd: 15° steps for rotation and reflection, width and height apart for scale. A click on empty space deselects. How far a drag scales or skews is this app's choice |
| Shape | Drag nodes and Bézier handles, marquee nodes, double-click a segment to add a node or a node to delete it, Delete removes nodes. Drag a rectangle corner to round it. Ellipse: drag its node inside for a pie, outside for an arc (Cmd = 15° steps). Polygon and star: drag an outer node to resize and turn every side (Cmd keeps the angle); a star's inner node sets its sharpness. Clicking a group edits the object under the pointer inside it (nested groups too), without ungrouping; tables, symbols, clones, symmetry groups and groups with a perspective are edited whole |
| Rectangle, Ellipse, Polygon, Star | Drag to draw; Cmd = equal sides, Shift = from the centre. Polygon sides and star points/sharpness in the property bar. A selected ellipse gets Whole ellipse / Pie / Arc and Change direction |
| Smooth, Smudge, Twirl, Attract and Repel, Smear, Roughen | Shape tool flyout. Select a curve or shape (or start the stroke on one), then drag along its outline; shapes become curves. Smooth eases the outline under the brush a little with each pass, then fits it back into Bézier curves when the stroke ends; Smoothness (50% to start) sets how much each pass does. Roughen adds spikes, out and in by turns, all along the stroke; going over roughened parts again adds nothing. Twirl and Attract and Repel work while the button is held, even without moving: Twirl turns the outline under the brush round its centre (Counterclockwise or Clockwise on the property bar), Attract pulls it in towards the centre and Repel pushes it out towards the brush's edge (Attract or Repel on the property bar). Each moves the outline most at the brush's centre and not at all at its edge, and fits it back into Bézier curves when the button is released; Speed (50% to start) sets how fast: at 100% Twirl turns a full turn a second at the centre. Brush size (20 pt) and spike size (3 pt) are on the property bar. One undo step per stroke. The starting sizes and speeds are this app's choice; pen pressure and tilt are not used. Smudge carries the outline along the stroke: drag across it (from inside out for an extension, from outside in for an indent). Smear pulls the part of the outline under the press out to the pointer, or in, as one smooth extension or indent; both fit the outline back into Bézier curves on release |
| Freehand | Drag; the stroke is fitted to Béziers; ending on the start closes it |
| Bézier, Pen | Click for corners, drag for smooth nodes, click the first node to close, Enter / Esc / click the last node to finish. Pen previews the next segment |
| 2-Point Line, Polyline, B-Spline | 2-Point Line: drag a straight line (Ctrl/Cmd keeps it to 15° steps). Polyline: click for straight segments. B-Spline: click control points; the curve is pulled towards them and starts and ends on the first and last. Both finish like the Pen tool (double-click, Enter, Esc, or the first node to close) |
| 3-point tools | 3-Point Curve: drag start to end, then click the point the curve passes through. 3-Point Rectangle: drag one side, then click to set the height. 3-Point Ellipse: drag one axis, then click to set the other. Rectangles and ellipses stay editable shapes, turned along the first edge. Esc drops the first edge |
| Dimension tools | Parallel Dimension and Horizontal or Vertical Dimension (Dimension flyout): drag between the two points to measure, then click where the dimension line goes (Esc cancels after the drag). Parallel measures along the line between the points; Horizontal or Vertical measures the horizontal distance when the line is pulled above or below the points and the vertical one when pulled beside them. The result is a group named Dimension: extension lines, the dimension line with filled arrowheads, and the distance in the display unit as 8 pt text over the line, turned along it so it never reads upside down. Segment Dimension: click a segment of an object (its end nodes are measured in a straight line, curved segments included), then click where the dimension line goes. Angular Dimension: drag from the vertex along the first arm, click a point on the second arm, then click where the arc goes; the label is the angle in degrees to one decimal, and an arc placed outside the arms measures the angle outside them (over 180°). Dimensions do not update when the measured objects move. The 8 pt text, 5 pt arrowheads and 2 pt overshoot are this app's choice |
| 3-Point Callout | Dimension flyout: drag from the point the callout points at to the bend of its leader, click where the leader ends, then type the text (Esc finishes). The text starts 3 pt past the end of the leader, level with it, and reads away from the bend: left-aligned when the leader ends to the right, right-aligned when it ends to the left. The leader is a 0.5 pt black line named Callout; it and the text are separate objects, and the leader stays if no text is typed. The 3 pt gap is this app's choice |
| Spiral | Spiral tool (`A`): drag its box; an even spiral from the centre out to the edge, turning the number of times set on the property bar (4 by default). Ctrl/Cmd makes the box square |
| Graph Paper | Graph Paper tool (Polygon flyout): drag its box; a group of equal rectangles, the columns and rows set on the property bar (4 × 3 by default, this app's choice). Ctrl/Cmd keeps the box square, Shift draws from the centre |
| Common Shapes | Common Shapes tool (Polygon flyout): pick a shape on the property bar (triangle, right triangle, parallelogram, trapezoid, diamond, hexagon, cross, four arrows, heart, callout) and drag its box; it comes out as a curve. Ctrl/Cmd keeps the box square, Shift draws from the centre. The shapes and their proportions are this app's own; they have no adjustment handles |
| Text | Text tool (`F8`): click the page and type artistic text; Enter starts a new line, arrows/Home/End move the caret, Backspace/Delete remove, Esc or another tool finishes. Click text to edit it, or double-click it with the Pick tool. Property bar: font family and style (the bundled Ubuntu Light plus the system's fonts), size in points, left/centre/right alignment; with nothing selected they set up new text. New text is black with no outline. Text moves, scales, shapes and converts to curves like any object, and exports as outlines. Glyphs are placed by their advance widths only: no kerning, ligatures or complex scripts |
| Character shifts, Align to Baseline | With artistic text selected, the Shape tool shows a node at the foot of every character: drag one to move just that character (Cmd: only up and down, or only sideways); the characters after it stay where they are. Shifts are saved, undoable, exported (as outlines) and stay with their character while you type. Text > Align to Baseline puts every character of the selected text back on its baseline and keeps sideways shifts; Text > Straighten Text puts every character back in its place (and takes text off a path, as before). Not yet available: rotating single characters, shift values in the property bar, character nodes on paragraph text and text on a path |
| Paragraph text | Text tool: drag a frame instead of clicking. Words wrap to the frame width and alignment works within it; lines that do not fit are hidden and the frame turns red. Frame width and height in the Properties docker. An empty frame stays when typing ends. Text > Convert to Artistic/Paragraph Text (`Cmd+F8`) switches either way without moving the text: wrapped lines become line breaks. Resizing with the Pick tool's handles or the property bar's W/H resizes the frame and the words rewrap; the glyphs keep their size. Other ways of scaling (Transform docker, Free Transform, Repeat, scaling a group) still scale the text |
| Edit Text | Text > Edit Text… (`Cmd+Shift+T`) with one text object selected: its words in a window, applied with OK (one undo step) or left as they were with Cancel. Works for artistic, paragraph and path text; editing a page number this way makes it plain text |
| Change Case | Text > Change Case…: Sentence case, lowercase, UPPERCASE, Title Case or tOGGLE cASE, applied with OK to the selected text objects, or to the text being typed into |
| Text Statistics | Text > Text Statistics: text objects, lines (as laid out), words, characters (spaces included) and fonts of the selected text, or of every text object in the drawing when no text is selected |
| Text Properties | Text > Text Properties… (`Cmd+T`) shows the Properties docker, with the selected text's words and size to edit and its font |
| Nonprinting characters | Text > Show Nonprinting Characters (on and off) marks every space with a dot and every paragraph end with ¶ on the text of the active page, on screen only; not on text fitted to a path |
| Columns | Text > Columns… with paragraph text selected: the number of columns (1 to 12) and the gutter between them (5 mm to start). The frame is split into equal columns; the words fill one column top to bottom and flow on into the next, and overflow only after the last. Saved with the drawing, undoable |
| Bullets and numbering | Text > Bullets and Numbering…: None, Bullets (•) or Numbers (1., 2., … counting the paragraphs with words) for the selected text or the text being typed into. Every paragraph gets its mark, and its lines (wrapped ones too) start past the widest mark plus half the font size. Not on text fitted to a path. Saved, undoable |
| Drop cap | Text > Drop Cap… with paragraph text selected: Use drop cap, and the lines dropped (2 to 10, 3 to start). The first letter grows so its capitals run from the first line's cap height down to the last dropped line's baseline; those lines wrap beside it. Turning it on removes bullets or numbers. Saved, undoable |
| Tabs | The Tab key types a tab into the text being edited. A tab moves on to the next tab stop, measured from where the line starts (the frame's or column's left edge for paragraph text). Text > Tabs… lists the stops of the selected text or the text being typed into: change a position, Delete one, or Add tab (half an inch past the last). Text with no stops of its own, and every tab past the last stop, moves on in half-inch steps. Stops are left-aligned only; no leader characters. Saved, undoable |
| Glyphs | Text > Glyphs: every visible character the font has, by code point, in a grid, in a window beside the dockers; the font and style start as the text being edited or selected, else the font for new text, and can be changed at the top. Click a character to pick it (its code shows below), then Insert, or double-click it: while text is being typed, it goes in at the caret; otherwise it is added as new artistic text in that font, centred on the page and selected. The window stays open |
| Find and Replace | Edit > Find and Replace… (`Cmd+F`) opens the Find and Replace docker (also under Window > Dockers). Find next (or Enter in the Find field) selects the next text object containing the words, on to the following pages and round to the first; Match case is optional. Replace changes the selected match and finds the next; Replace all changes every match in one undo step. Text in groups and PowerClips is found (the group or frame is selected); locked objects, hidden or locked layers and page numbers are left alone |
| Fit Text to Path | Select one artistic text and one shape or curve, then Text > Fit Text to Path: each glyph sits on the outline, turned to follow it, from the start, middle or end by the text's alignment; glyphs past the end are hidden. The text keeps a copy of the outline, so editing the shape afterwards does not move the text. Edit its words in the Properties docker. Text > Straighten Text makes it plain artistic text again, starting where it started |
| Tables | Table tool (Text flyout): drag a box for a table of equal cells, the rows and columns set on the property bar (3 × 3 to start, this app's choice); or Table > Create New Table… (rows, columns, width and height; the table goes in the middle of the page). Each cell is a rectangle with paragraph text inside, 2 pt in from its edges (this app's choice); the table moves, scales and exports as one object and is saved with the drawing. With the Table tool, click a cell to pick it, drag across cells or Shift+click to pick a block (it grows to take in any merged cell it cuts), and click the one picked cell again to type in it; the Text tool types into the cell it clicks, and a double-click on a table with the Pick tool picks a cell with the Table tool. Typing ends as with any text, and rows grow to fit their text. A palette colour fills the picked cells (or every cell when the whole table is selected), never the text. Table > Insert > Row Above, Row Below, Column Left, Column Right: as many as are picked, as high or wide as them; the new ones are picked, and merged cells across the insertion grow. Merge Cells: the picked cells become one, keeping every text, one per line (this app's choice). Split into Rows… / Split into Columns…: the one picked cell into that many equal parts; the first keeps the text, and grid lines are added only where none are. Convert Text to Table… (one text object): a row per line, cut into cells at Commas, Tabs or a user-defined character, or a cell per line with Paragraphs; columns and rows fit their text. Convert Table to Text…: paragraph text the size of the table, a line per row with the cells told apart the same ways (places covered by a merged cell are empty), or a line per cell. Not yet available: deleting, selecting and distributing rows and columns, Unmerge, Insert Rows/Columns…, dragging row and column borders, borders per side, cell margins and vertical alignment, Tab between cells |
| Grid, guidelines, snapping | View toolbar or View menu: Grid (every 5 mm by default; spacing in the Properties docker with nothing selected, thinned out when zoomed far out) and Guidelines. Drag from a ruler to add a guideline; drag one with the Pick tool to move it, back onto a ruler to remove it. Clicking a guideline selects it (Shift adds or removes; drawn red); Delete removes the selected ones. Guidelines belong to the page, are saved and undoable. Snap To (View menu or toolbar magnet): Pixels (the pixel grid of Pixels view, at the Export window's resolution; off by default), Document Grid, Guidelines (on by default), Objects (edges and centres), Page (edges and centre). New shapes, Bézier/Pen nodes, text, moved objects (by their edges and centre), scale handles and Shape-tool nodes snap within 6 screen points, per axis. The grid and guidelines snap only while shown. View > Alignment Guides: while moving objects or drawing, an edge or centre within reach of another object's edge or centre lines up with it, and a dashed green line runs across both. View > Dynamic Guides: while drawing, the pointer is pulled onto lines at 0°, 45°, 90° and 135° through other objects' corners and centres, and the line is shown. Both are off by default. Which targets are on by default, the 5 mm grid, the guide angles and colour are this app's choice |
| Fountain fills, transparency, eyedroppers | Properties docker and the Interactive Fill tool (`G`) property bar: No fill, Uniform fill (colour) or Fountain fill (linear or elliptical, start and end colours). With the Interactive Fill tool, click an object and drag across it to place a fountain; drag its ends to move them. Fountain fills live in the object's own space, so they move, scale and turn with it, and export to SVG, PNG and PDF. Transparency (0–100 %, the whole object) in the Properties docker and the Transparency tool's property bar. Color Eyedropper: click to pick a colour (fill, gradient colour at that point, outline, or the white page), then click a fill or outline to apply it. Attributes Eyedropper: pick an object's fill, outline and transparency, then click objects to apply them. Fountain fills have two colours; more stops, conical/rectangular fountains, patterns, textures, mesh fills and fountain transparency are not built |
| Smart Fill | Smart Fill tool (Interactive Fill flyout): click inside an area that object outlines enclose; the area (inside every closed shape around the click, outside every other one, with holes kept) becomes a new curve on top, selected. Property bar: fill colour (light grey by default, this app's choice) and Outline (off by default). Open curves do not bound areas; clicking outside every closed shape does nothing |
| Fill and outline | Palette: click = fill, right-click = outline, crossed swatch removes. Property bar (with a selection): outline width with presets (None, Hairline, 0.25–36 pt) and line style. Properties docker: fill colour; outline width, colour, line style (solid, dotted, dashed, long dash, dash dot, dash dot dot), corners (miter, round, bevel), line caps (butt, round, square), behind fill, scale with object; corner radius, sides, points, sharpness, name. Edits to several objects change only the setting you touched. Fills use the even-odd rule on the canvas and in every export |
| Overprint | Object > Overprint Fill and Overprint Outline (on and off, for the selection; on a group, for every member) mark the fill or outline to print over what is below instead of knocking it out. They are saved with the drawing and undoable. View > Simulate Overprints shows the result on the canvas: an overprinted part multiplies with the colours under it, as stacked inks do (white disappears). Multiplying is an approximation of how inks mix, not a separation-based preview. Convert Outline to Object passes the outline's overprint on to the new curve's fill. Not yet available: Overprint Bitmap, and the overprint setting in exported PDF (the PDF library has no option for it) |
| Proof Colors | View > Proof Colors (on and off) shows every colour on the canvas as it would print: fills, outlines, fountain fill colours, bitmaps and the page background go through a soft proof from sRGB to macOS's Generic CMYK profile and back (relative colorimetric), so screen colours the inks cannot reach, like pure blue, show duller. The drawing keeps its own colours, and exports are not changed. The menu item is unavailable if the profile cannot be read. Not yet available: choosing another printing profile, rendering intent or paper simulation |
| Group and lock | Group (`Cmd+G`), Ungroup (`Cmd+U`), Ungroup All, Lock, Unlock, Unlock All: title bar buttons and the Object menu. A group moves, scales and takes colours as one; SVG export writes it as `<g>`. Locked objects can be selected (padlocks instead of handles) but not moved, edited, restyled, grouped or deleted |
| Units | 13 units: inches, millimeters, picas, points, pixels (96 dpi), ciceros, didots, feet, yards, miles, centimeters, meters, kilometers. Steppers move about 1 mm in any unit |
| Transform | Property bar and Transform docker: X, Y, W, H, rotate, mirror |
| Shaping | With several objects selected, the property bar and Object > Shaping have Weld, Trim, Intersect, Simplify, Front Minus Back, Back Minus Front and Boundary. The result takes the target's fill and outline: the last object selected, or the bottom-most after a marquee. Curves stay curves. Trim and Intersect keep the other objects; Boundary adds an unfilled outline around the selection. Open curves can't be shaped |
| Combine, Break Apart | Combine (`Cmd+L`) joins objects into one curve styled like the target; where its paths overlap there are holes. Break Apart (`Cmd+K`) makes each path its own object |
| Join Curves, Convert Outline | Join Curves (Object menu) merges the selected objects into one curve and links open ends less than 1 mm apart; they meet halfway, and a path whose own ends meet closes. Convert Outline to Object (`Cmd+Shift+Q`) turns each outline into a filled curve of its colour, above the object (below for Behind fill); the object keeps its fill, or goes if it had none |
| Crop, Knife, Virtual Segment Delete, Eraser | Crop: drag the area to keep, then Enter, a double-click inside it or the property bar's Crop button (Esc clears it); it cuts the selected objects, or everything on the page when nothing is selected, and removes what lies wholly outside. Knife: drag a line across objects to cut each one it crosses into two objects, both selected. Virtual Segment Delete: click an outline to delete the part of it between the crossings on either side of the click (other objects' outlines or its own); on an open curve with no crossing there it goes to the curve's end, and a closed shape crossed fewer than twice goes whole. The object becomes an open curve, or is deleted when nothing is left. Groups, text and bitmaps are not cut, and text and bitmaps do not count as crossings. Dragging a box to delete several segments is not done yet. Eraser (`X`): drag to remove a round stroke from the selected objects (all objects it touches when nothing is selected); size in the property bar, default 5 mm. Closed shapes are cut with the boolean operations and open curves are split where they cross, so curves stay curves. Bitmaps are kept whole (Crop removes them only when wholly outside); Knife leaves groups and bitmaps alone |
| Arrange | Align (L R T B E C, P = centre to page): one object aligns to the page, several to the last selected. Distribute (three or more objects; Align and Distribute docker and Object menu): left, centres, right or spacing, horizontally or vertically, between the two outermost objects. Order: front, back, forward, backward, reverse order. Convert to Curves (Cmd+Q / Ctrl+Q), which also converts every member of a group |
| Edit | Undo/redo (every finished gesture is one step), cut/copy/paste (copy also puts the selection on the system clipboard as SVG, so it pastes into other apps). Edit > Paste Special… reads the system clipboard and offers the ways it can come in: Vector Studio objects (this app's last copy, where it was), SVG drawing (as curves, centred on the page and scaled down to fit) or Plain text (as artistic text, centred on the page); duplicate (offset set in the property bar), delete, select all, arrow nudge (distance set in the property bar, default 1 mm; Shift ×10). Step and Repeat docker (`Cmd+Shift+D`): number of copies, and for each direction an offset or a spacing between objects. Copy Properties From: choose outline pen, outline colour, fill and text properties, then click the object to copy from (Esc cancels). Select All › Nodes (or `Cmd+A` with the Shape tool) selects every node of the selected curve; Select All › Text selects every text object on the page; Select All › Guidelines selects every guideline of the page (drawn red), and Delete removes them |
| Repeat | Edit > Repeat (`Cmd+R`) does the last move, scale, rotation, mirror or nudge again to the current selection, about its centre, or runs the last selection command again (Duplicate, Align, Distribute, Order, Convert to Curves, Convert Outline, shaping, Combine, Break Apart, Group, Lock, Unlock). Typing values into position and size fields is not repeated |
| Clone | Edit > Clone makes a linked copy, placed like Duplicate. A clone follows its master's shape, fill, outline and transparency as they change, but keeps its own position, size and rotation. Changing the clone's own shape or style, or deleting the master, makes it an ordinary object. Groups and PowerClips cannot be cloned. The link is saved with the drawing |
| Objects docker | Every page's objects top-first; click to select, Shift/Cmd-click to add, double-click to rename, order and delete buttons |
| Layers | Every page has layers (Layer 1 to start), listed in the Objects docker with their objects. Click a layer to draw on it; eye and lock toggles hide it (not drawn, exported, hit or snapped to) or lock it (drawn, not selectable). Docker buttons: New layer, Delete layer (with its objects; the last layer stays), Move layer up/down, Move to active layer. Double-click a layer to rename it. Files without layers open with one |
| Pages | Insert, duplicate and delete pages from the page navigator, the Pages docker or the Layout menu. Layout > Document Options… sets the units, the page size (of the active page, or of every page), grid spacing, nudge and duplicate offset in one window; OK applies them, Cancel leaves everything as it was; changing units in it converts the values shown. Layout > Rename Page… renames the active page in the Pages docker (or double-click a page there). Layout > Go to Page… jumps to a page by number. Layout > Insert Page Number adds the page's number as artistic text centred near the bottom edge, in the font set for new text; it renumbers itself when pages are added, removed or moved, and typing into it makes it plain text. Layout > Page Background…: No background (white paper) or a solid colour for every page (colour button or hex), shown on the canvas and picked by the Color Eyedropper; with Print and export background on (the default) it comes out under the objects in SVG, PNG and PDF. Background changes are undoable and count as unsaved changes |
| QR codes and barcodes | Object > Insert > QR Code…: the text or link and the code's width (30 mm to start); a QR code (medium error correction) as one black curve named QR Code in the middle of the page, selected. Object > Insert > Barcode…: a Code 128 barcode (letters, digits, spaces and ASCII punctuation), bar width (0.4 mm) and height (15 mm) to set, with the text centred under the bars (grouped) unless Show text is off. Both are ordinary vector shapes afterwards, not linked to their content. The sizes are this app's choice; other barcode formats are not available |
| Bitmaps and bitmap effects | Bitmaps > Convert to Bitmap… draws the selected objects (with half their outline) into one bitmap that takes the top one's place in the stack: resolution (300 dpi to start) and transparent or white background. Bitmaps > Resample… changes one bitmap's pixel size, keeping its proportions unless unticked; its size on the page stays. Bitmaps > Straighten Image… turns the selected bitmaps up to 15° either way (positive is clockwise) about their centre, magnified just enough to fill their frame, so their pixel size and place stay and no corner is left empty; the preview has a grid to line things up against. Bitmaps > Bitmap Color Mask hides the pixels near one colour (Hide colors) or every pixel but those (Show colors): pick the colour with the colour button, type it as #RRGGBB, or click it on the preview; Tolerance (10% to start) is how far each channel may be from it. The mask is applied to the pixels (one undo step), not kept as a setting to change later. Bitmaps > Image Adjustment Lab… adjusts Temperature, Tint, Saturation, Brightness, Contrast, Highlights, Shadows and Midtones together (-100 to 100, 0 for no change), with a preview. Bitmaps > Remove Background makes the background transparent in one step: the colour most common around the bitmap's edge, and every pixel within 12% of it that joins the edge through such pixels, so the same colour inside the subject stays; the pixels next to the removed area fade by how near the background they are. Bitmaps > Crop Bitmap trims fully transparent rows and columns off the selected bitmaps' edges; the rest stays where it was, at the same resolution. The Lab's ranges and the 12% are this app's choice. Effects menu, on the selected bitmaps: Adjust (Auto Adjust, Tone Curve, Brightness/Contrast/Intensity, Color Balance, Hue/Saturation/Lightness, Grayscale), Blur (Gaussian, Motion, Radial, Smart), Distort (Pixelate, Ripple, Swirl, Wind), Noise (Add, Remove) and Sharpen (Sharpen, Unsharp Mask). Blurs extend the bitmap's edge pixels rather than fading past them. The starting settings and the five fixed node positions are this app's choice; the preview is in the window, not on the page |
| Trace Bitmap | Bitmaps > Trace Bitmap turns the selected bitmaps into curves. The curves go just above each bitmap, grouped, where the bitmap is, and are selected; the bitmap stays unless Delete original image is ticked. One undo step. Outline Trace… fills one curve per colour: Type of image (Line art, Logo, Detailed logo, Clipart, Low quality image, High quality image) sets Detail, Smoothing, Corner smoothness and Colors to start with, and each can then be changed. Centerline Trace… (Technical illustration, Line drawing) draws an unfilled line along the middle of each stroke instead, with round ends, as wide as the stroke is on average. Pixels less than half opaque are not traced. Bitmaps over 2000 pixels along a side are traced at that size. The settings each Type of image brings and the 2000-pixel limit are this app's choice; the result is one curve per colour, not one per area |

| Perspective | Object > Perspective > Add Perspective (one object or group, without bitmaps) switches to the Shape tool and shows a grid on the object with a handle on each corner: drag a corner and the object is drawn as if seen at an angle, straight lines staying straight. | Drop Shadow | Drop Shadow tool (Effects flyout): drag from an object to cast its shadow that far away; a click only selects. Property bar: offset across and down (once there is a shadow), opacity (50% to start), feathering (how far the edge fades out, 6 pt to start; 0 is a hard edge), colour (black to start) and Clear shadow; with nothing shadowed selected they set up the next shadow. ## Shortcuts

Tools: `F10` Shape, `Z` Zoom, `H` Pan, `F5` Freehand, `F6` Rectangle, `F7` Ellipse, `Y` Polygon, `A` Spiral, `F8` Text, `Esc` finishes a path, then clears the selection, then picks the Pick tool.
Edit: `Cmd+Z` / `Cmd+Shift+Z`, `Cmd+X/C/V`, `Cmd+D` duplicate, `Cmd+A` select all (all nodes with the Shape tool), `Cmd+Shift+D` Step and Repeat, `Delete`/`Backspace`.
Arrange: `Cmd+L` combine, `Cmd+K` break apart, `L R T B E C P` align, `Shift+PageUp/PageDown` to front/back, `Cmd+PageUp/PageDown` forward/back one.
View: `Cmd+=` / `Cmd+-` zoom, `Shift+F4` zoom to page, `Cmd+1` actual size. `PageUp`/`PageDown` change page.

`Cmd+Q` is Convert to Curves, so Quit (in the Vector Studio menu) has no shortcut.
